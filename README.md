# AgentArena
### AI Agent Performance, Reliability & Fault-Tolerance Benchmarking Platform

## 1. Project Overview
AgentArena is a platform designed to evaluate AI agents beyond simple task completion.

It measures whether AI agents can:
- Complete tasks successfully.
- Produce consistent results across repeated executions.
- Handle API failures and unexpected errors.
- Recover from temporary failures.
- Perform efficiently in terms of time and tool usage.

## 5. Installation and Execution

1. Download the project ZIP.
2. Extract the folder.
3. Open the folder in Visual Studio Code.
4. Install the Live Server extension.
5. Open index.html using Live Server.

No additional dependencies are required.

## 6. How It Works

Step 1: Select a benchmark task.

Step 2: Select the number of repeated executions.

Step 3: Choose a prompt condition.

Step 4: Select a failure scenario.

Step 5: Execute the benchmark.

Step 6: Compare Agent A and Agent B.

Step 7: Review execution traces and performance reports.

## 7. Current Limitations

- Agents are JavaScript-based scripted simulators.
- No real LLM API integration.
- Failure injection is simulated locally.
- Token consumption and actual API costs are not measured.
- Experiment history is stored in browser LocalStorage.
